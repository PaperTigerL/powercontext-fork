# 验证样例：一次完整的夜班

> 照着做即可复现第 5 节的结果。每一轮给出“你说什么 → 判定 → 写入什么 → 状态行是什么”。
> 状态全部来自 PowerContext 长期记忆，不是对话上下文。
>
> 前置：按 `README.md` 第 4 节部署 PowerContext（SeekDB）、Dify 1.9.1、模型，导入 `app.yml`，
> 填好 `PC_BASE_URL` / `PC_AUTH_TOKEN` 并发布。
> **从全新用户开始**（WebApp 隐身窗口，或 API 使用从未用过的 `user`），否则账本非空、状态不归零。

## 初始状态

- 该用户没有 scope（第一轮自动创建），账本为空；
- NPC 名字：团子；好感 0；记仇 0；已记 0 件事。

## 第 1 轮：恶作剧（会话 A）

你说：

```
我把货架上的布丁按颜色排成彩虹了，还给价目表画了两撇胡子。
```

- 判定：`prank`（命中 `彩虹` / `按颜色` / `画胡子`）
- 写入：`kind=npc-event`，`text=type=prank; warmth=-1; grudge=2; say=我把货架上的布丁按颜色排成彩虹了，还给价目表画了两撇胡子。`
- 预期状态行：

```
【小本子】好感 -1｜记仇 2｜已记 1 件事｜NPC：团子
```

## 第 2 轮：示好（同一会话）

你说：

```
给你带了根猫条，还有热豆浆。
```

- 判定：`gift`（命中 `猫条` / `带了`）
- 写入：`kind=npc-event`，`text=type=gift; warmth=2; grudge=0; say=给你带了根猫条，还有热豆浆。`
- 状态从记忆累加：-1 + 2 = 1
- 预期状态行：

```
【小本子】好感 1｜记仇 2｜已记 2 件事｜NPC：团子
```

## 第 3 轮：改名（同一会话）

你说：

```
以后你就叫小笼包吧。
```

- 判定：`rename`（`以后…叫 X` 正则命中，尾部语气词 `吧` 去掉）
- 写入：`kind=npc-name`，`text=name=小笼包`（不增加事件数）
- 预期状态行：

```
【小本子】好感 1｜记仇 2｜已记 2 件事｜NPC：小笼包
```

## 第 4 轮：翻旧账（**新建对话**，同一 user）

在 Dify WebApp 里点“新建对话”，输入：

```
你还记得我上次干了什么吗？
```

- 判定：`recall`（命中 `记得` / `上次`）；**不写入任何记忆**
- 预期：回答里明确提到“价目表画了两撇胡子”或“彩虹布丁”，状态行不变：

```
【小本子】好感 1｜记仇 2｜已记 2 件事｜NPC：小笼包
```

> 新会话的对话上下文是空的；它能答出旧事，只能来自 PowerContext。

## 第 5 轮：闲聊（同一新会话）

你说：

```
我今天有点困，站了一天。
```

- 判定：`smalltalk`；不写入
- 预期：正常闲聊，状态行仍为：

```
【小本子】好感 1｜记仇 2｜已记 2 件事｜NPC：小笼包
```

## 机器可读的期望值

见同目录 `expected-state.json`。判定与状态由 Code 节点计算，与模型无关；
台词措辞会随模型变化，**只看状态行与账本条目**即可验收。
